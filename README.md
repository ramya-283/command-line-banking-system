# 💰 Command-Line Banking System - Java

A simple and efficient console-based banking application built with Core Java and Object-Oriented Programming (OOP) principles.

### ✨ Features
- Create new bank account
- Deposit money
- Withdraw money (with balance validation)
- Check account balance
- View all accounts

### 🛠️ Tech Stack
- Java (Core)
- OOP Concepts (Encapsulation, Classes, Objects)
- Collections (ArrayList)

### 🚀 How to Run
javac Account.java Bank.java BankingSystem.java
java BankingSystem
